# Security

pvpn is a small hobby project, maintained by one person in their spare time.

## Reporting a problem

If you find a security problem, please **don't open a public issue**. Report it privately instead:

1. Go to the [Security tab](https://github.com/allandehn/pvpn/security) of this repo.
2. Click **Report a vulnerability** and describe what you found.

Only the maintainer can see private reports. Expect a reply within about 24 to 48 hours.

## What counts

For example: anything that could leak your traffic or DNS when pvpn says you're connected, expose your WireGuard keys, or let another program run commands through pvpn.

The missing kill switch is a known limitation, described in the README, not a vulnerability.

## Supported versions

Only the latest release gets fixes.
